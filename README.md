# Riou 脚本工具箱

个人用的 Linux 服务器管理脚本。因为总是记不住命令，每次都要重复敲同样的东西，所以让 AI 把我的习惯写进去了。

## 快速使用

```bash
curl -sL https://raw.githubusercontent.com/riwi002/mybox/main/riwi.sh | bash
```

## 主要功能

| # | 模块 | 说明 |
|---|------|------|
| 1 | 系统查询 | 系统信息、资源、网络状态 |
| 2 | 日常运维 | 更新、清理、安全加固、性能优化、监控排查 |
| 3 | 环境配置 | 常用工具一键安装 |
| 4 | 版本控制 | Git 仓库管理、提交推送 |
| 5 | 应用市场 | 常用应用一键部署 |
| 6 | 常用快捷工具 | 进程/网络/日志/快捷操作诊断面板 |
| 7 | 综合管理 | 1Panel、Nginx、Python |
| 8 | 后台工作区 | tmux 会话管理 |
| 9 | 容器管理 | Docker 容器/镜像/Compose 全管理 |
| 10 | 建站部署 | 一键建站向导、LDNMP环境、站点管理、反向代理、SSL证书、组件管理 |
| 11 | 集群控制 | 多服务器统一管理 |
| 12 | 密钥管理 | 用户/公钥/双证/三证/硬证/飞书/应急救援 |
