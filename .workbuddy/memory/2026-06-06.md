### GitHub 管理器 - 推送到远程超时修复
- 问题：`git push` 在 macOS 上网络不通时会卡住，因为没有 `timeout` 命令
- 第一次修复：添加了 `run_with_timeout` 函数，使用 `pkill -P` 杀子进程 + `kill` 杀主进程
- 问题未解决：`pkill -P` 无法正确终止 `git-remote-https` 子进程，`wait` 仍然卡住
- 最终修复：使用 `set -m` 启用作业控制创建独立进程组，`kill -TERM -$pid` 向整个进程组发信号，确保主进程和所有子进程同时被终止
