## Docker 全管理 — 优化加载速度

### 问题
`docker_manager_menu()` 每次打开菜单都执行 `docker ps -q`、`docker ps -aq`、`docker images -q`，
当 Docker 未运行或未响应时，这些命令会卡住 10-30 秒等待超时。

### 优化方案

#### 1. 新增缓存变量（第540-543行）
```bash
_CACHE_COLIMA_ACTIVE=false
_CACHE_DOCKER_CONTAINER_RUNNING=0
_CACHE_DOCKER_CONTAINER_ALL=0
_CACHE_DOCKER_IMAGE_COUNT=0
```

#### 2. 修改 `refresh_status_cache()` 函数（第612-621行）
- Docker 活跃时，用 `timeout 5` 执行 `docker ps` 等命令
- 将容器数/镜像数存入缓存变量
- 添加 Colima 状态缓存（`timeout 5 colima status`）

#### 3. 修改 `docker_manager_menu()` 函数（第24518-24532行）
- **使用缓存值**：`_dr=$_CACHE_DOCKER_CONTAINER_RUNNING` 等
- **未运行时不执行 docker 命令**：避免卡住
- **Colima 状态使用缓存**：`_CACHE_COLIMA_ACTIVE`

### 优化效果
| 场景 | 优化前 | 优化后 |
|------|--------|--------|
| Docker 运行中 | 每次执行3条 docker 命令 | 使用缓存（60秒有效） |
| Docker 未运行 | 卡住 10-30 秒 | 立即返回，不执行 docker 命令 |
| Colima 已安装 | 每次执行 `colima status` | 使用缓存 |
