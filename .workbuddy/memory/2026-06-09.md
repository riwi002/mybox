### 功能清单（21项）

| 分组 | 选项 | 功能 | 1pctl 命令 |

| 服务 | 1-4 | 启动/停止/重启/状态详情 | start/stop/restart/status |

| 其他 | 18-21 | 查看日志/更新/安装/卸载 | update/quick_start.sh/uninstall |

### 失联修复说明
当 1Panel 无法访问时（忘记安全入口、端口变更、IP限制等），
无需进入 Web 端，直接通过本菜单执行重置：
- 选项 5：重置安全入口（URL 后缀）
- 选项 6：取消域名绑定
- 选项 7：取消 HTTPS 强制
- 选项 8：取消 IP 访问限制
- 选项 9：关闭两步验证
- 选项 10：一键重置全部安全设置

### 技术要点
- 自动检测 1pctl 命令是否存在
- 自动读取 /opt/1panel/conf/app.yaml 获取端口和IP
- 所有操作通过 1pctl CLI 完成，无需浏览器
- 防火墙支持 firewalld / ufw / iptables 三种
- 语法验证 `bash -n` ✅ 通过
