## 环境配置批量操作添加一键换源 LinuxMirrors
- 在 `linux_tools()` 函数（环境配置，主菜单第3项）的「批量操作」区域新增 `35. 一键换源 LinuxMirrors`
- 来源: SuperManito 的开源项目 `https://github.com/SuperManito/LinuxMirrors`
- 官网: `https://linuxmirrors.cn`（备用 `edgeone.linuxmirrors.cn`）
- 三个子功能:
  - 1) 系统换源: `bash <(curl -sSL https://linuxmirrors.cn/main.sh)`
  - 2) Docker 安装与换源: `bash <(curl -sSL https://linuxmirrors.cn/docker.sh)`
  - 3) Docker 换镜像加速器: `bash <(curl -sSL https://linuxmirrors.cn/docker.sh) --only-registry`
- 支持 30+ 发行版: Debian/Ubuntu/CentOS/RHEL/Fedora/Rocky/AlmaLinux/Arch/Alpine/openSUSE/Gentoo/NixOS/Void Linux 等
- 交互流程: 功能介绍 → 子功能选择(1/2/3/0) → 确认提示 → root权限检查(非root自动sudo提权) → 下载脚本到临时文件 → 执行 → 后续建议
- 注意事项已注明: 需root权限、自动备份原源、需联网、换源后刷新缓存、小众架构可能不支持
- 提醒事项已注明: 建议低峰期操作、国内选阿里/腾讯/中科大、海外选官方/Cloudflare、备用域名
- 采用「先下载到临时文件再执行」方式，与 1Panel/3X-UI 分支风格一致
- 备份文件: `riwi.sh.bak_changemirrors_20260719`

## 应用市场添加虚拟机 Quickemu
- 在 `linux_panel()` 中新增 `4. 虚拟机 Quickemu`
- 来源: `https://github.com/quickemu-project/quickemu`
- Quickemu 是 QEMU 封装脚本，quickget 下载OS镜像 + quickemu 一键启动虚拟机
- 支持近 1000 种客户机操作系统: macOS/Windows/Linux/BSD/FreeDOS/Haiku 等
- 宿主要求: Linux 或 macOS（需GUI图形界面）
- 安装方式按发行版自动选择:
  - Ubuntu: PPA `ppa:flexiondotorg/quickemu`
  - Debian: GitHub releases .deb 包
  - Fedora: `dnf install quickemu`
  - Arch: `yay -Sy quickemu`（无yay时自动安装yay）
  - macOS: `brew tap quickemu-project/quickemu && brew install quickemu`
  - 回退: 源码编译 `git clone && cd docs && sudo make install`
- 注意事项已注明: 需GUI环境/需硬件虚拟化/macOS虚拟机需gdisk+mtools/安装需root但运行不需root/磁盘空间/源码安装需手动装依赖
- 提醒事项已注明: 更适合桌面Linux/Win11需TPM2.0/macOS仅Linux宿主可跑/ARM64软件模拟性能低/可用Quickgui前端
- 使用示例: `quickget nixos unstable minimal` → `quickemu --vm nixos-unstable-minimal.conf`
- 备份文件: `riwi.sh.bak_quickemu_20260719`

### 教训：Edit 工具 old_string 唯一性
- 首次编辑时 `old_string` 用了 `\t\techo ""\n\t\t;;\n\t  0)` 通用模式，在文件中多处匹配

- 修复方式：从备份恢复，改用 1Panel 分支独有的 `1panel.cn/docs` 内容作锚点，确保唯一匹配
- **以后编辑大文件：old_string 必须包含目标位置独有的上下文（函数名、独特字符串等）**
