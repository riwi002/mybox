## 修复 LinuxMirrors 脚本在 macOS bash 3.2 上的兼容性
- 报错: `declare: -A: invalid option` / `${current_lang,,}: bad substitution`
- 原因: LinuxMirrors 官方脚本使用 `declare -A`（关联数组）和 `${var,,}`（小写转换），都是 bash 4.0+ 特性
- macOS 自带 bash 3.2.57 不支持这些特性
- 修复: 在 linux_mirrors_switch 函数中增加 bash 版本检查
  - bash 4.0+ 直接运行官方命令
  - bash 3.x 尝试查找 /opt/homebrew/bin/bash 或 /usr/local/bin/bash 等高版本
  - 找到高版本就用它执行脚本
  - 找不到就给出安装提示（macOS: `brew install bash`）
- 注意: Linux 服务器（Debian/Ubuntu/CentOS等）默认 bash 4.0+ 不会有此问题
