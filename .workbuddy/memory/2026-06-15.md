## 修复：sudo 探测总是显示 No 的问题
- 原因：`sudo -n -lU` 依赖 sudo 会话缓存，无缓存时返回失败 → 正则匹配不到 → 显示 No
- 改为三层文件级探测，不依赖 sudo 命令：
  1. 检查 `/etc/sudoers.d/$username` 文件是否包含 `username ALL=(ALL)`
  2. 检查 `/etc/sudoers` 主文件
  3. 兜底：检查用户是否在 sudo/wheel 组

## 按 owen 操作习惯重构用户创建流程
- 合并为一个选项：「创建用户（含密码+密钥+sudo最高权限）」
- 创建流程分 5 步：创建用户 → 设置密码(交互式) → 导入 SSH 公钥(支持留空跳过) → 赋予 sudo NOPASSWD:ALL → 配置 SSH + 锁定密码登录
- 完成后自动探测验证：用户组、sudo 权限、密码状态
- 菜单精简为 3 个选项：创建/取消/删除
- 不再区分「普通」和「高级」用户，统一赋予 sudo 最高权限
