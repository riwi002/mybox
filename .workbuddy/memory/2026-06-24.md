## riwi.sh 新增飞书扫码 SSH 登录（feishu_ssh_manager）

用户要求在主菜单 12.密钥管理新增「飞书扫码」功能，使用飞书扫码登录 SSH。

### 技术说明
SSH 协议本身不支持飞书扫码（OAuth2），只能间接实现。用户确认走「飞书推送确认」方向：用 pam_exec 在 SSH 登录时向飞书群机器人推送消息，管理员在飞书 App 里看到登录提醒。两种模式：
- 通知模式（STRICT_MODE=0）：登录成功后推送通知，不拦截
- 严格模式（STRICT_MODE=1）：推送后等待管理员在 /tmp/riwi_fs_confirm 写 OK 才放行，超时（60s）拒绝

### 用户确认的方案
- 飞书机器人：群机器人 Webhook
- PAM 模块：pam_exec + Bash 脚本

### 完成的改动
- user_manager 菜单新增第 6 项「飞书扫码（SSH 登录飞书确认）」
- 新增 feishu_ssh_manager 函数（约 350 行），8 个子功能：
  1. 配置飞书机器人 Webhook（校验 URL 格式，存到 /etc/riwi/feishu_ssh.conf）
  2. 测试飞书推送（curl 发测试消息）
  3. 启用飞书 SSH 登录通知（部署脚本 + PAM optional + UsePAM yes）
  4. 启用严格模式（PAM required + STRICT_MODE=1，需输入 yes 二次确认）
  5. 禁用（从 PAM 移除飞书行）
  6. 查看当前配置
  7. 查看最近登录记录（last 命令）
  8. 卸载（删配置 + 脚本 + PAM 行）
- 新增 _feishu_deploy_hook_script 辅助函数：部署通知脚本到 /usr/local/bin/riwi_feishu_ssh_notify.sh
- 通知脚本逻辑：
  - 只在 PAM_TYPE=open_session 时触发（登录成功后）
  - 读 /etc/riwi/feishu_ssh.conf 配置
  - 构造消息（服务器/用户/来源IP/时间）curl 发到飞书 Webhook
  - 严格模式: 轮询 /tmp/riwi_fs_confirm 文件，60秒内写 OK 放行，否则 exit 1 拒绝
  - 日志记录到 /var/log/riwi_feishu_ssh.log
- 复用双证/三证的 _ssh_backup_configs / _ssh_apply_and_restart 辅助函数

- 飞书安全设置关键词必须填「SSH」（消息必须含此词才发送）
- Webhook URL 校验格式（必须 open.feishu.cn/open-apis/bot/v2/hook/ 开头）
